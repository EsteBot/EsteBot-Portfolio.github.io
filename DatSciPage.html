🧩 Experimental Design using Least Different Group Matching 🔎 PySimpleGUI Pandas Itertools Matplotlib re

Problem:

Assignment Complexity: Assigning pair-housed subjects to treatment versus control groups based on baseline data required minimizing initial differences while strictly preserving cage-mate pairs.

Scale: Evaluating thousands of potential group assignment combinations to find the absolute minimum variance was entirely impractical to perform manually.

Solution:

Algorithm & Interface: Developed a PySimpleGUI desktop app leveraging Pandas and Itertools to systematically compute all group permutations, identify optimal minimum-variance pairings, and generate Matplotlib visual verification.

🐁 Wheel Running Data Parsing & Automation 🔎 PySimpleGUI Openpyxl Matplotlib

Problem:

Data Deluge: Running-wheel experiments generated millions of timestamped revolution data points across multiple subjects and extended cycles.

Filtering Bottleneck: Manually filtering valid running bouts (>=3 RPM) and isolating activity between light (inactive) and dark (active) phases was labor-intensive and error-prone.

Solution:

Parsing Engine: Created a PySimpleGUI and Openpyxl desktop application to ingest, filter, and aggregate multi-subject running data by phase in seconds, complete with automated Matplotlib comparative graphs.

📄 Text-to-Excel Automation for Activity Data 🔎 Pandas Xlwt Matplotlib re

Problem:

Extraneous Data: Infrared beam-break chambers outputted massive, unstructured text files containing substantial superfluous data alongside target locomotion metrics.

Manual Friction: Manually extracting and formatting relevant time-bins for multiple subjects across multi-hour trials was painfully slow and prone to transcription errors.

Solution:

Text Parser: Built a PySimpleGUI desktop utility using regular expressions and Pandas to parse raw text outputs, normalize data into clean Excel spreadsheets, and auto-generate exploratory time-bin graphs.
