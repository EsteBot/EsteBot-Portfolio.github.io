⌛ Bout Time: A Mobile Logger for Behavioral Science 📱 Kivy Sqlite3

Problem:

Observation Bottleneck: Behavioral neuroscience experiments require meticulous segmentation of individual behavior occurrences across multiple subjects and observers, generating data logging friction.

Solution:

Mobile Logging App: Developed a Python Kivy Android application featuring real-time metric tracking (total behavior time, bout counts, last bout duration) via a press-to-record interface.

Automated Export: Streamlined data storage by transferring trial metrics directly into stats-ready Excel spreadsheets.

⚖️ Weight4It App: Simplifying Drug Formulations 📱 KivyMD

Problem:

Unit Conversion Friction: Converting animal gram weights to drug milligram doses per kilogram of body weight routinely confused novice researchers and threatened protocol accuracy.

Solution:

Mobile Dosing Calculator: Built a KivyMD app to automate dosage conversions across solution volume targets and total cohort body weights, displaying precise required weights in both grams and milligrams.

🧠 StaxAttax App: Stereotaxic Coordinate Calculator 📱 KivyMD

Problem:

Coordinate Calculation Risk: Computing 3D stereotaxic brain surgery targets (DV, LM, AP relative to bregma) via notebook math introduced human error, illegible record-keeping, and variable formatting across researchers.

Solution:

Stereotaxic Calculator: Created a KivyMD mobile app supporting Unilateral, Bilateral, and 2x Bilateral target calculations, outputting color-coded coordinate values instantly.

Digital Archiving: Features record-keeping metadata fields and calculation image export for standardized, seamless integration into shared lab databases.
