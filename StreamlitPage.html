🏨 Talk Hotel Data to Me: Date Flexible Viz with AI Assisted Data Queries 🚀 Google Gemini 2.0 (LLM) SQLite LangChain Altair

Problem:

Manual Logs: Management and business operations relied on static, manual logs and spreadsheets.

Visibility Gap: Difficulty spotting long-term trends, comparing seasonal occupancy, or querying specific metrics without extensive manual data digging.

Solution:

Data Engineering: Migrated static logs into a structured SQLite database for high-speed querying.

Natural Language AI: Integrated Google Gemini via LangChain to build a Natural Language-to-SQL engine enabling plain-English queries (e.g., "What was our average rate last weekend?").

Visual Dashboard: Deployed a, cloud-hosted Streamlit application featuring dynamic Altair charts for Occupancy, Sold-Out Pressure, and Maintenance Impact.

⛳ The Golfable Oracle: Personalized Playability Forecasts 🚀 Pandas Plotly

Problem:

Weather Uncertainty: Golfing conditions fluctuate hourly (e.g., pleasant now, rain in 2 hours at the 10th tee), making it difficult to optimize play windows without granular forecasts.

Solution:

Interactive App: Developed a dynamic Streamlit application enabling users to input custom location and playability parameters (min temp, max wind, max precipitation chance).

API Integration: Leveraged the Tomorrow.io API to compute metric differentials, highlight comfortable playing hours on interactive Plotly graphs, and project multi-day golfable hour totals.
