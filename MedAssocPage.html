Welcome to my MedStateCode page!

Domain-Specific Hardware Control & Behavioral Data Collection

Automating Med Associates Operant Chambers using MedState Notation (MSN) —a domain-specific state-machine programming language compiled into DLLs for real-time hardware execution and behavioral event logging in Med-PC.

Operant Chamber Schematic

Subject presses lever for reward. Reward schedules, timeout periods, and timestamped event logging are governed by custom MedStateCode procedures.

Domain Challenge:

Hardware State Control: Programming complex operant conditioning schedules requires mastering low-level MedState Notation (MSN) to manage precise hardware inputs, output relays, and real-time behavioral data capture without system latency.

Solution:

State Machine Engineering: Developed custom MSN procedures to automate reinforcement schedules, priming intervals, and timeout windows while generating standardized, timestamped data logs for downstream group analysis.

⚙️ Reinforcement by Design 🐀 MedStateCode

Operant Conditioning for Pellet Self Administration

Logic & Schedule: Governs a 90-minute trial delivering sugar pellet rewards upon lever presses. Features automated initial/inactivity priming pellets (3-min threshold) and a 30-second post-reward timeout interval.

Data Acquisition: Captures timestamped records of active lever presses, timeout presses, and total pellets delivered for rate-of-responding analyses.

🛠️ Leveraging Behavior 🐀 MedStateCode

Operant Conditioning for Liquid Reward Self Administration

Logic & Schedule: Delivers calibrated liquid volumetric rewards paired with a synchronized visual light cue upon correct lever presses, followed by an unrewarded timeout period.

Data Acquisition: Differentiates and timestamps reinforced vs. unreinforced lever responses to evaluate cue reactivity and extinction patterns.
