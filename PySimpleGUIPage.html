⏲️ Real-Time Behavioral Scoring with Excel Export 🖥️ KivyMD

Problem:

Manual Scoring: Quantifying freezing behavior as a fear response proxy required observers to manually check subjects every ten seconds, record on paper, and aggregate by hand.

Workflow Bottleneck: Multi-step manual entry into Excel created significant processing drag and high vulnerability to human transcription errors.

Solution:

GUI Tracker: Developed a Kivy-based desktop application enabling real-time checkbox logging at ten-second intervals.

Automated Export: Programmed backend calculations to output directly into stats-ready Excel spreadsheets detailing percentage freezing time per minute.

🧮 End Weight of Diluent Calculator 🖥️ PySimpleGUI

Problem:

Density Deviation: Quantifying pure ethanol (EtOH) ingested from gram-weight changes required accounting for the fact that ethanol's lower density relative to water complicates direct weight-to-volume conversions.

Solution:

Formulation Tool: Built a PySimpleGUI desktop application allowing users to input specific gravity, target volume percentage, and final volume.

Dual Metric Output: Automatically computes required component quantities in both milliliters and grams to ensure precise formulations for stock liquids.

⏱️ Behavioral Timer with Excel Data Output 🖥️ Tkinter Openpyxl

Problem:

Continuous Observation Limit: Quantifying social interaction behaviors required unbroken human observation without looking away for manual note-taking, making traditional multi-stopwatch setups inadequate.

Solution:

Multi-Behavior Tracker: Developed a Tkinter desktop application to track multiple behaviors, total durations, bout lengths, and discrete tallies simultaneously during live sessions.

Excel Integration: Automated openpyxl data formatting to output all session logs directly into custom Excel spreadsheets.
